# monet_gdt

The on-device wallpaper model in [libmonet](https://github.com/Telosnex/libmonet)
apps. From a wallpaper it scores 10 mood words (used to pick fonts),
picks a 3-color theme, and scores 29 decorative shapes. One ONNX graph,
5.55 MB, 10-15 ms on one Apple-silicon CPU core.

Every training image is CC0, public domain, or generated by an
Apache-2.0 model. Mood and shape labels come from Jev, a hosted
vision-language model (`api.typesafe.ai`). A teacher (PE-Core tiny,
384 px, fine-tuned) learns Jev's labels on 25K images; the student (the
teacher's first 6 blocks, 224 px) learns from the teacher on 75K images.
Color labels come from code: monet_ui's `MonetGdtRule20261030`, which
chooses colorful colors before large areas.

Version: 2026.10.30. Changes: [CHANGELOG.md](CHANGELOG.md).

## Usage

The built model is on Hugging Face:
[Telosnex/monet_gdt](https://huggingface.co/Telosnex/monet_gdt)
(`monet_gdt.onnx` and `monet_gdt_mood.json`).

```python
import numpy as np, onnxruntime as ort
from PIL import Image

session = ort.InferenceSession('monet_gdt.onnx')
image = np.asarray(Image.open('wallpaper.jpg').convert('RGB'))
scores, feature, colors, shapes = session.run(None, {'image': image})

shape_names = session.get_modelmeta().custom_metadata_map['monet_gdt.shapes'].split(',')
print(['#%02x%02x%02x' % tuple(c) for c in colors])  # e.g. ['#c4842c', '#ace4fc', '#9cd4fc']
print(shape_names[int(shapes.argmax())])  # e.g. 'puffy'
```

| Input / output | Shape | Meaning |
|---|---|---|
| `image` | uint8 [h, w, 3 or 4] | the wallpaper, any size (the graph resizes) |
| `scores` | float [1, 10] | raw mood scores, in the order of `lib/mood_words.WORDS`; `monet_gdt_mood.json` maps them to percentiles |
| `feature` | float [1, 192] | the image embedding the heads share |
| `colors` | int64 [3, 3] | primary, secondary, tertiary RGB (0-255) |
| `shapes` | float [1, 29] | shape scores; names in the `monet_gdt.shapes` metadata |

## Limitations

- Training runs on Apple silicon (PyTorch MPS) only.

## Building

Requirements:

- Mac with Apple silicon, 32+ GB RAM, about 40 GB free disk.
- Python 3.12 with [uv](https://docs.astral.sh/uv/).
- Flutter 3.47+ (for `tools/v2_labels`, which writes the color labels
  with [monet_ui](https://pub.dev/packages/monet_ui) 1.0.1).
- Labels: [Telosnex/monet_gdt_labels](https://huggingface.co/datasets/Telosnex/monet_gdt_labels)
  (all stored Jev answers and id lists, CC0), or a Jev API key
  (`USER_API_KEY_JEV`) to label mood and shapes from scratch.

To use the stored labels instead of calling Jev, fetch them first:

```sh
hf download Telosnex/monet_gdt_labels --repo-type dataset --local-dir labels
cp -R labels/jev labels/data .
```

Then skip the steps below that would overwrite them: `select_corpus.py`,
`build_manifest.py`, `label_mood_shapes.sh` and `label.py`.

```sh
uv sync
.venv/bin/python -u scripts/select_corpus.py      # choose the corpus (no images)
.venv/bin/python -u scripts/download_corpus.py    # images -> data/images
.venv/bin/python -u scripts/build_manifest.py     # split, licenses -> data/manifest.jsonl
sh scripts/label_mood_shapes.sh                   # Jev labels -> jev/
.venv/bin/python -u scripts/match_unsplash.py download    # wallpaper-like photos
.venv/bin/python -u scripts/train_teacher.py
AUG=1 EXTRA=data/matched.jsonl OUT_NAME=student_matched50k \
  .venv/bin/python -u scripts/train_student.py
STUDENT=student_matched50k sh scripts/rebuild_graph.sh   # shapes, color labels and head, graph, checks
.venv/bin/python -u scripts/label.py mood data/population_ids.json jev/mood_population.jsonl
.venv/bin/python -u scripts/wall_population.py    # font calibration -> fonts/wall_population.json
.venv/bin/python -u scripts/export_app.py mood out/v2/monet_gdt_v2.onnx
```

Outputs: the graph `out/v2/monet_gdt_v2.onnx` and the mood map
`out/app/monet_gdt_mood.json`. On an M4 Max: downloads about 1 h,
teacher 15 min, student 75 min, color labels 10 min, color head 20 min.

`rebuild_graph.sh` builds a base graph first (scores, feature, shapes,
and placeholder colors), then the color step on it: color data from the
base graph, labels from monet_ui, the color head, and the final graph.
Its checks stop the build if scores, feature or shapes differ from the
base graph, or if the role order differs from monet_ui's rule.

Notes:

- **Wallpaper-like photos.** Besides the corpus, the student trains on
  CC0 Megalith photos chosen because they look like wallpapers. The list
  (`data/selection_matched.jsonl`) is in the labels dataset, and
  `download` fetches the photos. Redoing the choice (`match_unsplash.py
  ref`, `scan`, `select`) needs Unsplash Lite as the reference; its terms
  don't allow redistribution, so it isn't included.
- **Font calibration.** The last three steps rank a wallpaper's mood
  scores against 1,500 wallpaper-like photos; see
  [docs/FONTS.md](docs/FONTS.md).
- About 1% of the Flickr photos have been taken down since Megalith was
  crawled; the build skips them.
- A few evaluation scripts (`score_d8.py`, `compare_teachers.py`,
  `learning_curve.py`, `repro_check.py`) need private test images and
  stop with a message if they're missing. The build doesn't use them.

## Tests

```sh
.venv/bin/pytest
```

Checks the graph's inputs and outputs, determinism, distinct colors, the
version, and that the mood map matches the graph. Graph tests are skipped
until the graph is built.
